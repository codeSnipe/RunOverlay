# RunOverlay

RunOverlay 是一款面向跑步视频的原生 macOS 数据蒙层工具。它将 FIT/GPX 运动数据与大疆、影石拍摄的多段视频按拍摄时间自动匹配，并批量导出带动态数据蒙层的视频。

## 当前里程碑

当前实现包含：

- SwiftUI 三栏深色剪辑工作台，分层素材列表、中央视频预览和侧边属性面板
- MP4/MOV 批量导入；左侧视频列表底部「导入」可同时选择视频文件或文件夹，递归扫描并自动匹配时间资源
- 支持将视频文件夹或 FIT/GPX 文件直接拖入窗口导入
- 按同目录同名将影石 `.lrv` 和大疆 `.LRF` 时间资源绑定到对应视频；容器缺少拍摄时间时回退使用文件名中的本地拍摄时间
- 左侧视频列表显示本次匹配采用的拍摄时间及来源（元数据/文件名/时间资源/手动），并标出相对运动开始时间的偏差；选中视频可查看完整运动时间范围和视频前后缺数据的时长，通过「修正时间」手动输入本地拍摄时间或恢复自动读取。修正会即时重新匹配、支持撤销并随项目保存，不修改原素材
- AVFoundation 视频元数据读取
- 视频列表、选择和播放预览
- 左侧视频列表支持按住鼠标左键拖动框选（从视频行或空白区域开始）、⌘/Shift 多选，导出弹窗继承选择；弹窗与导出进度均显示视频缩略图、名称
- 左侧视频标题行提供“清空”按钮，确认后只移除项目中的全部视频，保留运动数据、蒙层设置及磁盘原文件，可用撤销恢复
- 左侧运动数据标题行也提供“清空”按钮，确认后清除当前项目的 FIT/GPX 来源、运动样本及视频匹配结果，轨迹与数据预览即时清空；保留视频、蒙层设置和磁盘原文件，可用撤销恢复
- 点击左侧视频列表使其获得焦点后，可用 ↑ / ↓ 逐个切换选中的视频并更新中间预览，列表会在需要时滚动到选中项
- 左侧视频列表上方统一设置本次导出比例（16:9、9:16、4:3、3:4 等），选中视频仅显示“左转 90° / 右转 90°”，可重复点击到所需方向；不同素材像素尺寸但比例相同不会误报。旋转后仍不匹配时即时显示黄色告警，批量导出前再次提醒可能留黑边
- 视频画面右上角支持全屏预览，保留实时数据蒙层与播放进度；普通和全屏预览均可用空格或回车播放/暂停、左右箭头各跳转 5 秒，Esc 返回编辑器
- 工作区左下角提供截图按钮和「包含数据层」选项（默认关闭），从当前暂停位置截取 PNG；截图沿用视频旋转及导出画幅留黑效果，通过保存面板选择目标文件，不覆盖已有图片
- 截图旁的「编辑封面」支持使用当前暂停帧（可继承「包含数据层」选择）或导入 PNG/JPEG/HEIC 图片；可添加多层文字、拖动位置，分别设置字体、字号、颜色、描边与阴影，字号最高可达到画面高度的 80%；点选中的文字会显示虚线编辑框和四角手柄，拖动手柄可等比缩放字号，悬停手柄时光标变为斜向拖拽样式。文字可在所有人物前方、所有人物后方，或点击画面中的指定人物并置于其后；已选人物用黄色轮廓提示。导出 PNG/JPEG 后关联当前视频，封面文字和素材来源自动保存到项目，下次打开可继续编辑；若未手动保存项目，自动恢复文件位于应用支持目录。更换底图时会清除旧人物选择，重新修改封面后需重新导出；编辑器以独立窗口打开，标题栏可来回拖动、边角可拖拽缩放，窗口尺寸与位置自动记忆，窗口打开期间再次点击「编辑封面」会切换到当前选中的视频
- 封面编辑窗口沿用主工作台的深色调，素材来源、添加文字与导出集中在顶部；中央以大画布为主，右侧按图层、文字字体、外观和人像遮挡分组编辑，底部状态栏显示操作结果与预览尺寸
- 封面编辑的素材、文字、导出、图层与人像操作使用统一的大尺寸按钮；字体改用可搜索的列表面板，颜色项也提供更大的选择区域
- 封面字体选择入口及可搜索列表均同时显示字体名称和用对应字体渲染的「字体」二字预览，方便比较字体外观
- 内置四款 Google Fonts 开源简体中文字体：钟齐志莽行书（Zhi Mang Xing，适合水墨行书标题）、马善政毛笔字（Ma Shan Zheng）、站酷快乐体（ZCOOL KuaiLe）、站酷小薇体（ZCOOL XiaoWei），随应用分发即可使用，无须用户安装；四款均为 SIL Open Font License 1.1，原始许可文件位于 `Sources/RunOverlayApp/Fonts/`
- 封面字体选择器提供「中文字体 / 全部字体」Tab，默认仅显示能实际绘制常用简体汉字的字体；全部字体列表仍将中文字体置顶。内置四款与常见系统中文字体显示中文名称，旁边保留原字体名及「字体」二字预览，搜索支持中文名称和原名
- 修正斜体文字与编辑边框中心错位：无原生斜体字面的中文字体会使用轻量合成斜切，并按同一文字排版中心计算预览和导出边框
- 封面文字图层可独立切换加粗、斜体；外观设置提供 10 组文字色与描边色推荐搭配，一点即可应用，也仍可分别自定义两种颜色与描边粗细。预览、导出、项目自动保存保持一致
- 封面右侧的每条文字后面均有复制按钮，副本继承当前字体、配色、角度与人像遮挡等设置，稍微错开放置并自动选中，可单独拖动和修改，保存项目后可继续编辑
- 推荐配色色卡直接用当前所选字体显示「示例」二字，并应用该配色的文字色和描边色；可在点选前预览真实的封面文字效果
- 封面字体注册、中文字体筛选及推荐配色的缩略图缓存已从编辑窗口视图拆出；色卡预览与实际应用使用同一描边宽度规则，调整字体或描边时会更新预览
- 封面编辑参考大号胶囊按钮的视觉层级：导出封面与当前选中的素材来源为实心强调色，添加文字及未选素材来源为描边胶囊；按钮沿用软件的薄荷强调色而非参考图中的蓝色
- 全应用操作按钮统一沿用相同设计语言：主操作实心薄荷胶囊、次操作描边胶囊；视频列表、蒙层属性、时间轴、草稿、批量导出和轨迹校准使用适配区域尺寸的紧凑胶囊与图标按钮。原有 Tab 仍保持成组切换形态，通过统一底板、选中底色和短下划线提升层级，不与操作按钮混淆；系统菜单和文件选择器仍使用 macOS 原生控件
- 封面文字拖拽时，选框和文字在同一画布上同步移动、缩放；人物遮挡蒙版固定在底图位置，不随文字移动，右上角导出按钮不会因预览重绘反复闪烁或禁用。每个置于人物后方的文字图层可单独调整「遮挡强度」：0% 时文字不被遮挡，100% 时人物内部文字完全隐藏，预览和导出的效果一致；旧项目按 100% 读取
- 封面文字可单独旋转：右侧提供 -180°～180° 滑杆与角度输入框，画布选框上方有直接旋转的圆形手柄；旋转绕文字中心进行，拖动、缩放、人物遮挡、预览与导出保持一致，旧项目缺少角度字段时默认 0°
- 封面文字拖动靠近图片中心时，按实际文字选框水平或垂直中心分别自动吸附，并显示短虚线对齐参考线；离开吸附范围后可继续自由拖动，斜体文字也按视觉选框居中
- 封面制作时点击图片空白区域或画布留白会取消文字选中与编辑框；点击其他文字可再次选中，点击右侧属性控件则保持当前选中状态，取消选中不会修改文字内容
- 封面采用视频帧时，每次从工作台重新打开「编辑封面」都会取当前播放位置的新帧并保留文字布局；若重新打开的是用户导入图片，仍保留图片来源。更换底图会清除旧人物选点及已导出封面的关联，避免旧遮挡位置沿用到新帧
- 主页面左侧底部新增「版本更新记录」，可查看应用当前运行版本以及已确认的 0.1.0-012～020 安装包功能；普通 Xcode Debug 构建另显示「开发中」，不将本地构建误归为已发布版本
- 项目保存与重新打开
- 自动匹配状态领域模型
- FIT/GPX 本地解析与运动数据标准化
- 按拍摄时间批量自动匹配
- 配速、距离、心率、累计爬升、卡路里和完整轨迹实时预览；卡路里需源文件提供，不会凭空估算
- 单视频时间偏移校准
- 九套蒙层模板（含参考跑步分享画面设计的新项目内置默认「跑步聚焦」、赛道节奏、冲线时刻、山径攀升、夜跑光迹和「赛场实况」）；「跑步聚焦」左侧以更窄的区域纵向排列带当前位置点的白色轨迹、距离、配速、运动时长和心率，顶部居中放置动态进度条，右下角一行显示年月日时分秒。当前里程位于进度条上方并跟随进度移动，起点 0km 与本次运动总里程固定在下方两端。进度模块采用轻薄半透明底板，其他原有图层默认无实心底板；已保存项目和默认草稿不被自动覆盖。全部 13 种图层直接显示为四列数据卡片；点击创建或切换显隐，铅笔可分别设置位置、尺寸、整体和背景透明度及文字大小，画布上也能拖动与缩放；预览日期时间会自适应卡片宽度，不显示省略号
- 新增独立「轨迹爬升」图层：按整段跑步距离绘制海拔起伏曲线，白点随当前视频中的运动位置移动，同时显示累计爬升与起终点里程；可单独调整位置、大小、透明度、文字大小和爬升单位（米/英尺），默认带轻薄底色。使用同一曲线数据进行播放预览、截图与视频导出，不修改现有模板或已保存项目；无海拔记录时不绘制虚假曲线
- 各卡片按数据类型提供专属设置：配速 `/km` 或 `/mi`、距离 `km` 或 `mi`、海拔与爬升 `m` 或 `ft`；日期时间卡片可选完整日期时间、仅日期、仅时间；运动时长卡片可选自适应或 `HH:MM:SS`。所有设置均独立保存至项目和分享草稿，预览与导出一致；不适用的卡片不显示对应选项
- 蒙层草稿可存为默认样式，也可通过 `.runoverlay-template` 文件导出分享和导入复用；右侧草稿「导入」可选择单个、多个文件或文件夹，递归导入其中的草稿，分享文件不含素材路径
- 工作区左上角可按 Tab 样式切换原始、16:9、9:16、4:3、3:4 视频画幅，预览和导出保持一致
- 工作区分辨率以及右侧属性栏的模板样式、速度平滑、导出比例、格式、并行任务直接使用 Tab 切换；强调色提供当前颜色的取色框和推荐颜色下拉面板，可自选任意颜色或点击推荐色
- 预览区右上角可独立切换视频文字为中文或英文，不改变软件界面语言；选择随项目保存，导出与预览一致
- 项目级统一配置及单视频覆盖
- 最近 50 步可逆编辑操作记录，可在中间预览区右下角点击撤销/重做图标，或使用 ⌘Z / ⇧⌘Z；项目参数、图层、草稿、素材重连及导出选择均记录。新建或打开项目会重置历史；播放定位、保存文件、安装包和实际视频导出不作为可撤销操作
- H.264/MP4 与 HEVC/MOV 批量导出
- 批量导出前勾选具体视频、全选或取消全选；导出队列进度、取消、失败重试和 Finder 定位
- 批量导出（包括取消或部分失败）结束后自动解除编辑锁并将左侧从批量勾选恢复为当前视频单选；完成弹窗仍可查看结果及重试失败项，关闭弹窗后可立即选择其他视频截图或编辑封面；后台成功导出后自动收起完成状态
- 点击「后台继续」会收起进度弹窗，批量视频仍按原队列导出，顶部保留进度入口并可随时重新打开查看/取消/重试；主界面可继续切换视频、播放、截图和编辑封面，当前批次每段视频的时间、蒙层、数据与导出参数在点击开始时固定，不受后台操作影响。编辑项目素材、导出目录和新建/打开项目仍需等待任务结束
- 缺失素材扫描重连、项目连素材打包
- 删除单个或清空视频、重新导入运动数据后立即重新检查资源状态；视频缺失提示会随列表更新，FIT/GPX 自身仍缺失时则保留独立提示，并可点击运动数据区域重新导入
- 顶部窗口工具栏不重复展示导入、保存与导出操作；打包项目及重连缺失素材在菜单栏「文件」中，保存项目仍可使用 ⌘S
- 导出磁盘空间预检和任务期间防闲置睡眠
- 导出目录采用安全书签恢复时会在当前沙盒里实际验证可写；选择、更换、开始导出、失败重试及每个任务开始时均检查。目录授权失效时明确提示重新选择，避免 AVFoundation 反复报权限错误；失败任务可在导出弹窗里更换目录后重试
- 核心模型与匹配逻辑单元测试
- 使用 `demo` 中两段真实大疆视频和 FIT 数据，可选运行短片段真实导出验收，比较带蒙层/纯视频在轨迹区域的像素、横竖屏尺寸、音轨、时长及随时间变化的运动数据

拖入文件夹时会递归扫描 `MP4/MOV/M4V` 视频、`FIT/GPX` 活动文件和 `.runoverlay` 项目，并自动配对同名 `.lrv` / `.LRF` 时间资源；大疆视频如 `DJI_20261002111755_0086_D.MP4` 在容器缺少拍摄时间时可从文件名读取本地时间，不再弹窗报告配对和忽略文件数量。若发现多个活动文件，自动使用排序后的首个活动，并提示其余文件未导入。

## 运行

要求：Apple 芯片 Mac、macOS 14+、Xcode 16+。

```bash
open RunOverlay.xcodeproj
```

在 Xcode 顶部选择 `RunOverlay` scheme 和 `My Mac`，按 `⌘R` 即可运行。
工程包含 App Sandbox、用户选择文件读写权限和 `.runoverlay` 项目文件关联。

也可以在终端构建：

```bash
bash Scripts/build_debug.sh
```

该脚本在 Debug 构建成功后清理本项目的旧 Xcode、SwiftPM 构建目录与中间缓存，保留最新的
`.build/SmartEditDerivedData/Build/Products/Debug/RunOverlay.app` 以便直接运行。

Xcode 中选择 Product → Archive 可创建归档。未配置 Apple Developer Team 时，归档仅供本机内部预览；对外分发前需配置团队签名、Developer ID、公证和应用图标。

## 内部安装包

在项目根目录运行：

```bash
bash Scripts/package_app.sh
```

首次生成 `RunOverlay-0.1.0-001.pkg`，后续按根目录已有安装包递增为 `0.1.0-002` 等。`MARKETING_VERSION` 为 `0.1.0`，打包时 `CFBundleVersion` 为三位构建号（如 `001`），应用的 `RunOverlayDisplayVersion` 为完整版本 `0.1.0-001`。安装包元数据使用 macOS 可识别的 `0.1.0.001`，安装目标为 `/Applications`。脚本不覆盖旧包，也不会安装或启动应用。当前安装包为未签名的内部测试包。

需要 Debug 构建时运行 `PACKAGE_CONFIGURATION=Debug bash Scripts/package_app.sh`。Debug 安装包以 `-Debug.pkg` 结尾，与 Release 共用递增构建号；安装后会替换 `/Applications/RunOverlay.app` 中的同名应用。
