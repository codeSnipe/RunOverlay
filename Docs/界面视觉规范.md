# RunOverlay 工作台视觉规范

此规范用于 macOS SwiftUI 编辑界面，不改变视频里蒙层模板的配色。设计参考为 [CapCut Desktop](https://www.capcut.com/tools/desktop-video-editor) 的视频预览优先级与深色剪辑工作台，以及公开的 [UI UX Pro Max Skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) 中关于对比度、交互状态和响应式排布的检查原则。不复制剪映的品牌标识、图标或素材。

## 布局和颜色

- 左侧是素材库，中间是最暗的视频预览舞台，右侧是略亮的属性面板；底部播放区与工具栏各占一条内容高度。
- 所有界面颜色集中在 `EditorTheme.swift`。深灰按「舞台 → 面板 → 表面 → 抬升」排列，避免系统默认灰块和多种强调色混用。
- 青绿色仅用于主操作、拖拽反馈和辅助焦点；图层卡片的亮黄色表示正在显示，暗灰色表示隐藏。缺失素材仍用红色警示，匹配状态仍保留原有语义色。
- 视频比例变化只影响中间视频画布，控制条和图层卡片不得随视频伸缩。

## 组件与状态

- 左侧素材行保留缩略图、文件名、时长、尺寸和数据匹配提示；框选与多选不能触发视频导出或删除。
- 右侧将模板、草稿、图层、视频信息与导出设置分为清晰的独立区域；标题与内容的层级靠字号、间距和表面深浅建立。
- 交互控件保留 macOS 键盘焦点与 VoiceOver 标签。全部 11 种图层固定在四列卡片中；亮黄表示显示，暗灰表示隐藏，点击未添加的卡片会创建图层。右侧不设逐图层编辑区；图层的位置和大小在视频画布上点选、拖动或缩放。
- 空项目展示简洁的导入引导。导出弹窗继续显示缩略图、文件名、勾选状态和进度。

界面默认深色；视频本身仍按原始色彩播放和导出。原有导入、播放、蒙层编辑、草稿及导出功能不因主题样式改变。
