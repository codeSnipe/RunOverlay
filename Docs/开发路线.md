# RunOverlay 开发路线

## 产品边界

- 首版仅支持 Apple 芯片与 macOS 14+
- 输入为 DJI、影石的普通平面 MP4/MOV，可导入 4K
- 一个 FIT/GPX 活动对应 10～50 个视频
- 按拍摄时间自动匹配，允许时间偏移和轨迹位置校准
- 输出为最高 1080p SDR 的 MP4/H.264 或 MOV/HEVC
- 保留原始音频，不提供视频剪辑
- 全部运动数据与视频处理均在本地完成

**首版实现边界**：自动镜头点和口播文字作为审阅建议，用户可改入点/出点；声轨源区间保持连续，不允许这些建议自动裁掉讲话。手动导入素材没有可靠拍摄时间或 FIT/GPX 记录时，成片保留视频中已有的数据蒙层，但不会重新计算、烧录或伪造运动数据。版本一用于完整原声和镜头拼接；更高级口播/B-roll 重排需补足对应跨来源的时间映射与口播锁定编辑流程。
